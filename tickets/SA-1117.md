This PR builds the Survey Assist API Docker image once and deploys exactly that image to every environment, identified by its digest (`sha256:...`) rather than a tag. Each later environment only gets an image that has already passed the smoke tests in the environment before it. The NatCen pipeline also refuses to deploy unless that environment's Gemini model setting is in place.

```
Developer
   │  merge to main
   ▼
GitHub (survey-assist-api)
   │  triggers
   ▼
Cloud Build: cloudbuild_dev_and_sandbox.yaml
   │  test → BUILD IMAGE ONCE → push to registry → get digest sha256:abc
   ▼
Dev / Sandbox   (deploy sha256:abc, smoke tests)
   │  release tag vX.Y.Z
   ▼
cloudbuild_promote_preprod.yaml
   │  copy same image to releases repo (no rebuild), check digest still sha256:abc
   ▼
Pre-prod   (deploy sha256:abc, smoke tests)
   │  check: pre-prod running sha256:abc?
   ├──────────────────────────────┐
   ▼                              ▼
cloudbuild_promote_prod.yaml   cloudbuild_promote_natcen.yaml
   │                              │  + check GEMINI_MODEL_NAME set
   ▼                              ▼
Prod (sha256:abc)              NatCen (sha256:abc)
```
