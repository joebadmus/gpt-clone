**SA-1123: Centralise the UI testing proxy API in the CI/CD project**

**Description**
The UI testing proxy (the proxy API plus its network, NAT IP and service account) is built by the `ui-testing` module in each environment. Right now that means sandbox and NatCen. Each copy has its own outbound IP, which makes allow-listing and upkeep harder.

- Point the environments that use the proxy at the shared one.
- Remove the proxy from sandbox and NatCen once the new one is working.

- Where should the CI/CD project's Terraform live?
- Who can plan and apply in the CI/CD project?
- Is the current proxy IP allow-listed anywhere outside our Terraform?
