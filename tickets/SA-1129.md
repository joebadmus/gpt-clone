cd survey-assist-terraform

**2. Check nothing changes by default (sandbox)**
```
cd survey-assist-sandbox
gcloud config set project survey-assist-sandbox
gcloud auth application-default login
terraform init
terraform plan -target=module.firestore-otp
```
You should get "No changes" for the OTP module.

**3. Check the flag works (local only, don't commit)**

Temporarily add this line inside `module "firestore-otp" { ... }` in `survey-assist-sandbox/services.tf`:
```

```
Then run:
```
terraform plan -target=module.firestore-otp
```
You should see one in-place update, `paused = false -> true`, on `google_cloud_scheduler_job.firestore-otp-cli-scheduled`, with nothing created or destroyed.

```

```
