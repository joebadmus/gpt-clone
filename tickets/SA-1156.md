The current proxy config may already route to NatCen, so this could be a one-line change, or no change at all.

**How the proxy routes today**
- [proxy-api/nginx.conf](survey-assist-terraform/proxy-api/nginx.conf) takes a URL like `/sayt-ui/<environment>` and sends it to `sayt.<environment>.survey-assist.gcp.onsdigital.uk`.
- The environment part can be any lowercase name with hyphens, so there's no fixed list of environments.
- NatCen's UIs live at `sayt.natcen-external-sandbox.survey-assist.gcp.onsdigital.uk`, and the same for survey, themes and genie.
- So `/sayt-ui/natcen-external-sandbox` should already reach NatCen.

**What decides it**
- The thing that matters is which environment name the tests will send. That's Dan's smoke test ticket, which this one blocks.
- If the tests send `natcen-external-sandbox`, nothing needs changing. We test it and close the ticket.
- If they send a shorter name, like `sandbox-external` or `natcen`, nginx needs a small mapping from that name to `natcen-external-sandbox`. That's a few lines.
- Either way, a config change only goes live once the proxy image is rebuilt and redeployed through its Cloud Build.

**Quick test to see if it already works:**
```bash
PROXY=$(gcloud run services describe proxy-api --project=survey-assist-sandbox --region=europe-west2 --format='value(status.url)')
curl -s -o /dev/null -w "%{http_code}\n" -H "Authorization: Bearer $(gcloud auth print-identity-token)" "$PROXY/sayt-ui/natcen-external-sandbox/login"
```
- `200` means routing already works.
- `403` means the proxy got through but NatCen blocked it, probably the IP allow list. That would make it a different fix.
- `404` or `502` means it isn't reaching NatCen.
