# SA-1278: Load testing: tune Cloud Run and GKE scaling from the sandbox results

**Epic:** SA-962 (load testing)
**Suggested labels:** SAYT public test
**Assignee:** Joe
**Depends on:** SA-1277 (sandbox results)

## Description

If the sandbox runs show slow responses, errors or bottlenecks, the infrastructure needs tuning before the final pre-prod run. This ticket makes those changes through Terraform, re-runs the affected scenario in sandbox to confirm the fix, and records the settings to carry into pre-prod (SA-1279).

If SA-1277 shows no problems against the agreed limits, close this ticket with a note saying so.

## Approach

1. From the SA-1277 results, identify the bottleneck (for example Cloud Run instances, cold starts, the API, the vector store or LLM quota).
2. Choose changes based on the evidence. Possible changes:
   - **Cloud Run:** concurrency per instance, min instances (to avoid cold starts), max instances, CPU and memory, and CPU allocation.
   - **Vector store on GKE:** replicas, autoscaling and node pool size.
   - **OTP service and API:** the same Cloud Run settings, if they're the bottleneck.
   - **LLM:** a quota increase, if 429s were seen.
3. Make the changes through Terraform PRs to sandbox, and update the changelog.
4. Re-run the scenario that failed in sandbox. Compare before and after on the dashboard.
5. Record the final settings and their cost impact for SA-1279.

## Things to be aware of

- Change one thing at a time where possible, so it's clear what helped.
- Higher min instances and max instances cost more. Note the cost of each change.
- Agree with Matt whether the sandbox changes stay in place or are reverted afterwards.

## Definition of done

- [ ] Bottleneck identified from the SA-1277 results (or none found, and the ticket closed with a note)
- [ ] Tuning changes made through reviewed Terraform PRs
- [ ] Re-run in sandbox shows results within the agreed limits
- [ ] Before and after results recorded on Confluence
- [ ] Recommended pre-prod settings and their cost passed to SA-1279
