Here are the commands to pull the change and re-run the NatCen plan, plus an optional sandbox check.

**NatCen**
```
cd survey-assist-terraform
git pull
cd survey-assist-natcen-sandbox-external
gcloud config set project survey-assist-sandbox-external
terraform init
terraform plan -out=tfplan
```

**Check the result**
```
terraform show -no-color tfplan | grep -E "will be (created|destroyed|replaced)|must be replaced|has moved" 
terraform show -no-color tfplan | grep -iE "container_cluster|gke-nodes|gke-sayt-pods|whitelist"
```
- The first command should show `config-v3` being created, and only `lb-ingress-from-api` being destroyed.
- The second should print nothing, which means no GKE parts are being created.

**Sandbox (optional)**
```
cd ../survey-assist-sandbox
gcloud config set project survey-assist-sandbox
terraform init
terraform plan -out=tfplan
terraform show -no-color tfplan | grep -E "has moved|must be replaced|will be destroyed"
```
You should only see "has moved" lines for the GKE resources, with nothing replaced or destroyed.

Don't run `apply`, just send me the output.
